# MI (BCI IV 2a -> 2b) setup audit, 2026-11-28

Read-only audit plus run-tree setup. Nothing was trained. Paper values are not stored here.

## Data

- **Source, 2a** (`MI/MI_C2/fullchannels`, 5 folds): the PC clone, `M:\Earth` and `L:\plstm`
  copies are byte-identical (md5 5/5). Per fold 1901 / 403 / 288 trials (train / val / test),
  22 channels x 1125 samples (-0.5 to 4 s at 250 Hz), left/right hand only, test 144/144.
  Every test set is one whole subject (A01 to A05), so 4 of the 9 subjects are never tested.
  No trial is in two splits of a fold.
- **Builder**: `M:\Earth\datasets\helpers\data_perfoldExtraction_BCI_2a.m` + `dataFeeder_MI.m`.
  Test subject = fold i; a validation subject drawn with `rng(1000+i)` (twister) is merged into
  training (subjects 4, 3, 6, 1, 7 for folds 1-5, reproduced); the val split is a 20%
  trial-level sample of the training-pool subjects (so val is within-subject); train-only
  per-channel z-score. The inputs it reads (`*_binary_withPreCue.mat`, 2b `*_with_precue.mat`)
  and the raw GDF files are no longer on `M:`, so the folds cannot be rebuilt from there.
- **Target, 2b, repo / `M:` copy (11 Oct 2025): not usable.** All five files hold the same 400
  trials of one 2b subject (B01's three training sessions; built when only B01 existed):
  fold 1 test only and unstandardised, fold 4 train only, folds 2/3/5 train/val, no test.
- **Target, 2b, `L:\plstm\datasets\folds\MI\MI_C2\targetdomain1` (5 Nov 2025): valid.**
  Same builder, all 9 subjects (6520 trials, 2 ch x 1125), test = B01 to B05
  (720 / 680 / 720 / 740 / 740 trials), no trial in two splits, labels stored categorical.
  The HPC MI target results have exactly these test sizes, so they ran on these files.
  Copied (md5-verified) to `F:\Phase-Aware-LSTM-mi-runs\folds\MI\MI_C2\targetdomain1`.
- 2a and 2b are different subject pools, so source/target subject overlap is impossible.
- `MI_C2/dualchannelsource` is empty everywhere: no channel-selection source exists for MI.

## Run trees (`F:\Phase-Aware-LSTM-mi-runs`)

- `_mi_hpc`, `_mi_ours`: copies of `replication` + `utils` from this branch; only MI visible
  under `datasets\folds` (`fullchannels` junction to the PC clone, `targetdomain1` junction to
  the F: copy). `_mi_hpc\pretrainedModels` is a junction to `pretrainedModels_hpc` (HPC source
  nets extracted with `extractHPCSourceNets`); `_mi_ours\pretrainedModels` receives our
  threefry source runs.
- Variant `miHPCOptions` (this PR): the HPC option routing above; Graz EEGNet/Transformer
  option files copied verbatim from `L:\plstm\helperLibrary\modelframe\trainingoptions`.
- `replication/diagnostics/miSetupCheck.m` loads every fold, prints the variant's options and
  scores each extracted source net on its fold against the HPC evals.
