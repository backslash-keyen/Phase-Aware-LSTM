# Routine: collection round

Run on request, or after each stage lands.

1. Read the **For the coordinator** section of every `docs/sessions/*.md`.
2. Re-check each note at the current commit. Drop what is no longer true.
3. Sort what's left:
   - **answer**: you can answer it from the tree or `keyen.md`; answer in the handoff.
   - **route**: another scope owns it; put it in that scope's handoff under **Next**.
   - **bring to Keyen**: a decision. Group these by what they unblock, each with a recommended
     default, in one message through the coordinator chat.
4. Clear the notes you handled from each handoff.
5. Append one logbook entry: how many notes, where each went.
